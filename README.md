## Website

Built with HTML, CSS, and vanilla JavaScript. Includes responsive layouts, light/dark themes, project repositories, certificate links, and a downloadable CV. No installation or build step is required.

- `index.html` — content and structure
- `style.css` — responsive styles
- `script.js` — theme switch
- `resume.docx` — English CV
- `check.cjs` — checks for section links, assets, and theme behavior

Open `index.html` locally, or run `python -m http.server 8000` and visit `http://localhost:8000`.

Run checks with `node check.cjs`.

## Deployment

GitHub Pages publishes the repository root from the `main` branch. Changes committed or pushed to `main` automatically trigger deployment.
