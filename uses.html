The tools behind
the code.

The hardware and software I use every day to write, test and ship backend code — and why each one earned its place.

01

Hardware

Asus Zenbook 14

My main laptop — light enough to carry to class every day, with enough power to run Spring Boot, a database and an IDE side by side.

MSI monitor

A second screen for docs, pull requests and API responses, so the code always stays in view.

Asus mouse

Simple, reliable and comfortable through long coding sessions.

QKZ earphones

Music on, distractions off — my switch into focus mode.

02

Development

IntelliJ IDEA

My main IDE for Java and Spring Boot: smart refactoring, a great debugger, and running tests in one place.

Visual Studio Code

For quick edits, front-end files, Markdown and config — fast to open, easy to extend.

Cursor

An AI-first editor I use to explore unfamiliar codebases and try out ideas quickly.

SQL Server Management Studio

Writing and testing queries, inspecting data, and checking that what the API saved is really in the database.

03

AI assistants

Claude

A partner for thinking through designs, explaining tricky code and reviewing tests.

ChatGPT

Quick answers, debugging ideas and a second opinion. I always verify AI output before it goes into a commit.

04

Everyday

Spotify

Focus playlists that keep me in the zone while I code.
